    <h1 align = "center">CRT-MultiApp</h1>
</p>
<p align="center">
    
Originally a quiz app made in Python with TKinter where you can put in a list of player names and a list of questions, and be tested on them!
But it is now a general fun app that has a CRT style screen and a bunch of cool options via a Text Terminal type interface.

There are also a bunch of other features too! Such as _rickrolls_, a _gamble_ feature and default player and quiz questions, along with other projected ideas that aren't do do with the main **quiz** function. I am planning on adding more features later!

</p>

The **projected** OS versions will be:
 - Windows (x64)
 - MacOS (15 - Apple Silicon)
 - Linux (Ubuntu)
 - If more **OS**s are requested, then create a [Suggest Issue](https://github.com/sadgituser/CRT-MultiApp/issues/new?template=bug_report.md) with the code for the build.yml GitHub Actions file!
